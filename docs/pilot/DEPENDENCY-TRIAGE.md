# F0 dependency advisory triage

2026-10-18: fresh `npm audit --json` still reports 36 affected packages: 22 HIGH, 14 MODERATE, zero CRITICAL. These include inherited advisory chains, not 36 independent exploitable paths. `npm ls ... --all` confirmed actual installed paths. No dependency was forcibly upgraded or downgraded in F0.

Registry checks: latest braces is 3.0.3 and node-forge is 1.4.0, both still affected. No safe compatible fix for those roots was available. Parser and decoder fixes cross the installed dependency versions and need a dedicated compatibility change. Audit suggestions to downgrade Expo to 44 / React Native to 0.72 or NativeWind to 2 were rejected as incompatible. No advisory is marked resolved merely because its parent is build-only. Runtime decoder denial-of-service remains a P1 follow-up.

Primary advisories:

- [braces recursion denial of service](https://github.com/advisories/GHSA-vfj7-8cjw-p6xm): no patched version listed.
- [node-forge signature validation](https://github.com/advisories/GHSA-86w9-cpqp-85rv): no patched version listed.
- [decode-uri-component malformed input](https://github.com/advisories/GHSA-vcc3-ghjq-m6fr): fixed in 0.5.0; installed routing chain uses 0.2.2.
- [PostCSS selector parser complexity](https://github.com/advisories/GHSA-rj75-hqrm-r3gf): fixed in 7.1.6; installed parser is 6.1.4. Trusted build-time CSS is outside the advisory's untrusted request-path case.
- [uuid external output buffer bounds](https://github.com/advisories/GHSA-w5hq-g745-h8pq): patched in 11.1.1/12.0.1/13.0.1; xcode depends on uuid 7.0.3. Backend application IDs use Node crypto.randomUUID, not these vulnerable output-buffer APIs.
