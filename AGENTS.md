## 1. Project Overview

We are building **Maidaan**, an AI-powered sports matchmaking and coaching mobile application using Expo and React Native.

Maidaan solves three connected problems faced by recreational sports players:

- Teams can struggle to find replacement players when someone cancels at the last minute.
- Solo players often have no organized way to discover and join nearby games.
- Professional sports coaching can be expensive and inaccessible.

The app connects:

- individual players
- team captains
- indoor sports hubs / venue owners
- platform administrators

The initial sports supported are:

- Cricket
- Badminton
- Padel

The core product includes:

- sports and onboarding flow
- authentication
- player profiles and skill levels
- nearby match and open-slot discovery
- map and list views
- match details
- join requests
- captain acceptance/rejection workflow
- real-time one-on-one and group chat
- notifications
- AI-powered coaching through text and voice
- match history and basic player statistics
- hub / venue profiles
- organizer and admin management flows

The project is a Final Year Project, so the implementation should feel production-quality while remaining approachable enough to explain during evaluation and demonstration.
